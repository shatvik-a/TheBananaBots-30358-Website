Meet PEELZ

Our flagship 2025-2026 offseason robot engineered for speed, accuracy, and reliability.

High-Speed Mecanum Drivebase

Equipped with 4x GoBILDA 435 RPM Yellowjacket motors paired with 104mm mecanum wheels, providing 360° maneuverability with instant acceleration.

  • Frame: Custom 3D-Printed Pattern Plates
  • Intake: High-grip silicone compliant roller intake
  • Launcher: 360° Rotating Active Turret Launcher

Sub-Centimeter Odometry & Computer Vision

Featuring the goBILDA Pinpoint Odometry Computer with 2x 4-bar pods and Limelight 3A vision pipeline for high-precision localization.

  • Odometry: goBILDA Pinpoint Odometry Computer with 2x 4-Bar Pods
  • Vision Engine: Limelight 3A processing high-FPS vision pipelines
  • Localization: High-speed hardware odometry & Limelight tag tracking
  • Match Performance: 100 point average solo match score
LimelightAutoPipeline.java 
public class BananaLimelightAuto extends LinearOpMode {
    private Limelight3A limelight;
    private Follower follower;

    @Override
    public void runOpMode() {
        limelight = hardwareMap.get(Limelight3A.class, "limelight");
        limelight.pipelineSwitch(0);
        limelight.start();

        follower = new Follower(hardwareMap);
        waitForStart();

        LLResult result = limelight.getLatestResult();
        if (result != null && result.isValid()) {
            // Pedro Pathing Bezier Curve Trajectory
            Path scoringPath = new Path(
                new BezierCurve(new Point(startPose), new Point(scorePose))
            );
            follower.followPath(scoringPath);
        }
    }
}
